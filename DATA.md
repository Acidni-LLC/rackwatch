# Data statement
All alerts, logs, the client "Acme Dental Group", hostnames, serials, and people are **synthetic**, generated by `datagen/generate.py --seed 42`. IPs use RFC 5737 documentation ranges; domains use `.example`. Fake PII is planted deliberately to test the scrubber. The sample rack image is not a photograph of real equipment: it is our own render (`scripts/render_sample_rack.py`) made photorealistic with Muse Image (`muse-image-1.0`, dev time only), with the fictional sticker text repainted from `data/rack/layout.json`. The sample voice note is synthesized locally at dev time. No real client data or PII is included.
